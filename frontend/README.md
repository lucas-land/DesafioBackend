# Frontend

A interface faz parte do sistema de matrículas e depende da API NestJS.

O passo a passo completo (MySQL, arquivo `.env`, administrador e os dois processos) está no [README da raiz do repositório](../README.md).

Para subir somente esta pasta, com a API já em http://localhost:3001:

```bash
npm install
npm run dev
```

A aplicação abre em **http://localhost:5173**.
